# Ultra Battle Runtime — Showcase Build v2.7.4

UBR 是一个可静态部署的剧情联动 Web 战斗运行时原型。当前版本仍然使用纯 HTML / CSS / JavaScript，不需要 npm 构建。



## v2.7.4：贝利亚战斗曲

- 接入用户提供的贝利亚战斗音乐并转为项目统一使用的 OGG。
- 贝利亚第一阶段、银河追逐、第三阶段能量场以及最终帝斯修姆光线对拼共用同一条连续音乐；转阶段不重播、不重新定位。
- 本版本不修改贝利亚攻击、判定、场地或对白逻辑。


## v2.7.3：贝利亚斩击 / 射击 / 第三阶段特殊回合重做

- 修复第二、第三阶段终极格斗仪斩击收尾看不到巨镰光波的问题：旧版第二阶段把巨镰安排在回合结束前约 0.7 秒，720ms 预警尚未结束 BulletSystem 就已经停掉。现在为蓄力、跨场飞行和 Z 格挡完整预留约 1.95 秒。
- 巨镰超破坏光线改为真实跨越战斗框的巨大红黑月牙波；蓄力阶段可见边缘月牙与 Z 提示，随后光波实际穿场，Z 格挡窗口与光波靠近玩家的时间重合。斩击回合以这次格挡作为收尾，不再额外叠一发帝斯修姆光线干扰判断。
- 贝利亚射击三种语言重新区分：扇形射击保留可读缝隙；幽灵式射击改为带移动安全走廊的弯曲下坠弹；MTT 式射击改为四拍左右墙阵，每拍保留两条安全通道。第三阶段不再把九组墙阵重叠，而按“扇形→漂移→墙阵”固定谱面交替。
- 修复混合射击回合重复执行同一 fan 循环两次的代码错误。第三阶段混合射击也改为分段交接，避免多个完整弹幕组同时占满战斗框。
- 第三阶段转场特殊回合按用户提供的 29 秒参考视频重新拆成完整脚本：红/紫边缘纹章 → 蓝色对角长链 → 紫色交叉长链 → 红色中心放射花环 → 蓝紫边缘压迫 → 白色碎片雨 → 单发巨大斜向帝斯修姆光线。贝利亚始终作为场内中心对象存在，背景能量场同步红/紫/蓝切换。
- 第三阶段特殊回合由 17.8 秒延长到约 22 秒，为各视觉段落留下实际可操作时间；所有结构按固定编排保留连续可走路线，不再使用高速随机堆满全屏。

## v2.7.2：贝利亚之爪连续夹击修正

- 贝利亚之爪从多个互相断开的单次 hazard 改为一个连续 authored sequence；普通/强化/最终分别连续夹击 5 / 6 / 7 次。
- 回合第一帧上下爪阵就处于预备姿态并直接显示安全缺口；第一轮给予约 1.9 秒读位时间，之后每次张开后立刻切换下一处缺口，不再出现中间空白停顿。
- 爪阵从预备深度合拢到完全闭合，再退回预备深度，而不是每次完全消失；玩家始终能读到下一轮结构。
- 缺口位置被限制在实际窄框可移动区域内部，避免随机到边缘外形成理论上无法进入的“假安全区”。
- 对应贝利亚利爪回合时长调整为约 12.1 / 13.5 / 16.0 秒；第三阶段最后一次夹击结束后约 0.26 秒直接衔接帝斯修姆光线。

## v2.7.1：贝利亚节奏 / 场地恢复 / 表现层修正版

- 贝利亚敌方回合不再在可见攻击结束后留下 1~3 秒空场；5 套普通攻击按各自攻击长度单独收紧回合时长，并在攻击结束时立即恢复人物与普通战斗框。
- 银河追逐和终局能量场结束时统一执行 Belial arena cleanup：特殊 class、Battle Frame 内联尺寸和 Canvas 尺寸全部复位；Canvas 在贝利亚战内改为绝对定位，不再把 500px+ 特殊场地高度泄漏给【技能】/【道具】菜单。
- 菜单/对白中的贝利亚不再使用通用圆角 DOM 拼块，改成专用的扁平矢量轮廓；头部、手臂、终极格斗仪可单独做说话、指人、狂笑、举杖、帝斯修姆蓄力等差分。
- 敌方回合期间顶部头像退场，贝利亚本人直接由 Canvas 在战斗框中移动和出招；射击、雷电、斩击、爪击、巨镰与帝斯修姆都有对应姿态和换位，银河飞行加入残影。
- 贝利亚回合开始台词改为舞台气泡 + 人物动作，不再每次冻结在通用对白框中。

## v2.7.0：贝利亚最终战全面重置

- 贝利亚改为真正的角色型 Boss：攻击、嘲讽、挨打与玩家使用道具时都有对应动作，并会在战场周围持续换位，不再固定站在顶部。
- 加入行为反应对白池：回合开始 / 回合结束 / 玩家被击中 / 玩家攻击贝利亚 / 使用道具 / 银河追踪球反伤 / 濒死与最终光线对拼都有变化台词；不会识别玩家具体奥特曼或形态，只以“赝品 / 冒牌货”等方式进行泛化嘲讽。
- 第一阶段重做为终极战斗仪决斗：三类红黑射击、灭杀雷电、蓝橙斩击、Z 时机格挡巨镰光线、贝利亚之爪窄框夹击。
- 第二阶段阈值后的下一次敌方回合变为约 19 秒银河追逐战：战斗框被斩开成长纵向窗口，追踪光球可以被引回贝利亚，Z 可射击击碎流星与大型陨石。结束后恢复普通菜单回合。
- 第三阶段阈值后的下一次敌方回合变为约 17.8 秒大型能量场战：按提供的视频结构使用紫 / 蓝 / 红能量背景、四周结构弹幕与最终大型帝斯修姆光线，之后继续正常 HP 战斗。
- 第三阶段普通射击 / 雷电 / 斩击 / 利爪组合末尾可突然补上一发超宽帝斯修姆光线，方向包含横向、竖向与两种斜向。
- HP 归零后不再创建旧的 `belial-clash-qte` 覆盖层。最终帝斯修姆光线直接在当前 Canvas 战斗界面中进行：玩家持续按住 Z / Enter / Space 抵住光线，画面持续震荡，稳定后把光线逐步反推回贝利亚；松开过久会持续受伤，未能反推成功不会被系统自动判胜。

## v2.5.9：古兰特王橙蓝光束判定修正

## v2.5.5：古兰特王重做

- 红外线感应器：左右光管先显示蓝/橙预警，再连成整条感应光束向下扫落；特定回合会短暂停顿后按原颜色顺序倒带上升。
- 超级手臂：巨型机械手臂直接伸进战斗框，连续投掷石块、钢板和杂物；每一波保留移动安全间隙。

- 光弹扫射：左右斜上方炮管同时工作，连续波形光弹前线向下扫荡；安全走廊按固定节拍左右移动，不依赖随机数决定生死。
- 古兰镭射：场内炮孔先追踪、再锁死玩家位置、最后发射；玩家可在锁定后闪开，并通过站位把射线引向战斗框顶部中央的古兰特王本体，对 Boss 造成反击伤害。

## v2.5 当前重点：原创路线重新建立战斗身份

v2.4 的 `READ / EXISTENCE 三点教学 / ARMOR 接缝 / EXPOSED / DOMINATION` 方案不再作为当前原创路线设计。v2.5 不给原创路线添加“训练记录”“适配试炼”“标准答案”等背景设定；卡正文仍然决定玩家为何进入战斗，UBR 只负责怪兽登场、实际交锋、阶段变化和结果回传。

- **杰顿 → 海帕杰顿**：第一阶段借鉴方向防御的规则变化，把玩家固定到四向防御；来袭内容仍然是杰顿自己的火球、波状反击与瞬移佯攻。高威力光线会被屏障吸收并在敌方回合返还。进入海帕杰顿后恢复自由移动，战斗语言改为高速瞬移、残影追击、暗黑火球和更强的吸收返还。
- **格利扎**：完整使用第一形态、第二形态、最终形态。第一形态对玩家攻击主动闪避并显示 `MISS`；第二形态保留错位、背部光束与异常位移；最终形态真正实体化，同时获得更宽的怪兽能力攻击组。
- **古兰特王**：取消接缝小游戏与 ARMOR 条。古兰特王的身体本身会向战斗框推进并压缩可活动区域，多方向炮火同步封锁；随着 HP 阶段推进，装甲在模型上逐步开裂，伤害穿透也随之提高。

## v0.6：美尔巴高空追击重做

v0.5 的美尔巴只是把六块平台摆进一个固定画面里，跳跃高度也偏低，平台本身没有形成真正的追逐目标。v0.6 将这一模式重写为纵向滚动的爬楼式追击。

### 核心循环

美尔巴平时处于攻击范围之外。

```text
追击
→ 连续向上跳跃
→ 镜头跟随高度滚动
→ 到达本轮要求层数
→ 弱点 / 核心暴露
→ 攻击或技能窗口
→ 命中后美尔巴重新拉开高度
→ 下一轮再次追击
```

普通攻击和技能在弱点未暴露时无法直接命中。菜单中的“攻击”会显示为“追击”；到达目标高度后，它才重新变回“攻击”。

### 平台模式调整

- 每轮默认需要爬 9 层。
- 平台向上连续生成，而不是全部固定在同一屏。
- 镜头随高度向上滚动。
- 基础跳跃高度约 130 CSS px，平台层距约 74 px。
- 增加跳跃缓冲和短暂 Coyote Time，手感不再要求卡死落地帧。
- 掉落不会重置整轮，只退回最近进度附近并扣血。
- 顶层会直接显示发光核心目标。
- 场内显示 `ASCENT x / 9`，这是追击进度而不是“第几回合”。

### 美尔巴攻击窗口

成功登顶后，只开放【攻击】和【技能】。

- 暴露状态下防御下降到 0。
- 暴露窗口受到额外伤害倍率。
- 普通攻击如果 MISS，会浪费这一次窗口并重新开始追击。
- 命中后弱点关闭，美尔巴重新升空。

## v0.8 — 高斯专属路线：混沌利多利阿斯

新增第五场战斗：**混沌利多利阿斯**。

同一场战斗支持两种胜利逻辑：

### 普通战斗

迪迦和高斯都可以直接攻击，把敌方 HP 降至 0，以 `VICTORY` 结束。

### 高斯净化路线

使用高斯月神模式时，敌人 HUD 会出现 `CALM`。

高斯的专属行动：

- **呼唤**：下一轮开启净化领域。
- **接近**：下一轮出现更多混沌碎片，但敌方攻击也会更密集。
- **守护**：下一轮开启净化领域，同时降低受到的伤害。

净化领域开启后：

- 白色弹体仍然是敌方攻击，需要躲避。
- 黑紫色菱形是混沌碎片，需要主动接触。
- 接住碎片会提升 `CALM`。
- 碎片回到上方的混沌核心会降低 `CALM`。
- 玩家受伤会轻微降低 `CALM`。
- 直接攻击怪兽会显著降低 `CALM`，所以强攻和饶恕是互相冲突的路线。

`CALM = 100%` 后，**满月光波**解除锁定。使用后以 `MERCY` 结束战斗，而不是把怪兽 HP 打空。

普通玩家/迪迦不会获得 CALM 条，也不会把混沌碎片净化；对他们而言碎片就是另一种需要回避的特殊攻击。


## v0.9 — 迪迦区域 Boss：基里艾洛德人Ⅱ
