# Leo Route v1.6 — 不是被救，而是学会站起来

这一版把雷欧路线从“主动反击的一场实验战”扩成三场真正拥有共同主题、但各自改写战斗规则的战斗。

## 1. 马格马星人 / 红基拉斯 / 黑基拉斯

三人从开场就在场，马格马星人不是后半段追加的第三个敌人。

- 红、黑基拉斯维持 `GIRAS SPIN`，高同步时正面输出被显著压低。
- Z / Enter 的主动迎击用于顶开双子冲阵。
- `反向旋转`、`切进内圈`、回旋飞踢会真正拆掉旋转中心。
- 马格马星人的斩击持续封住双子的接缝，所以不能只盯着两只怪兽。
- 第二阶段“**大沉没**”不是简单加速：海潮成为新的横向/纵向压迫层，必须在浪和三人围杀之间保持重心。
- 双子倒下后，马格马星人撤退；不会硬把它变成第二个血条 Boss。

## 2. 普雷夏星人

核心规则是 **真实缩小**。

### Phase 1 — 魔法使

普雷夏用瞬移、浮游瓦砾和空间切线作战。这里先教玩家看杖尖，而不是突然丢出缩小机制。

### Phase 2 — 一寸雷欧

- 雷欧的 Battle Core 半径真实缩小到原来的约 40%。
- 普通攻击仍然能按，但实际伤害只有 1–2 点，明确表现体型差距。
- 敌人模型和场地视觉放大，普通碎石变成大型障碍。
- “气球”是会收缩的圆形牢笼；玩家必须在完全闭合前逃出。
- 连续撑过两个完整微小化敌方回合后，才进入奥特之王演出。

### Phase 3 — King Hammer / Ultra Mantle

奥特之王用 King Hammer 恢复雷欧体型，Ultra Mantle 进入实际操作：

- Z / Enter / Space 展开披风反射窗口。
- 紫色魔法弹不再只是躲避对象；精确反射会把伤害退还给普雷夏。
- `展开披风` ACT 可扩大反射时机。

因此同一个敌人的魔法先改变“世界尺度”，随后又被 Ultra Mantle 改写为玩家的反击手段。

## 3. 布莱克恩多 — 最后的圆盘生物

这场不使用银河的“伙伴给英雄力量”，也不使用迪迦的“全世界成为光”。雷欧最终回的主题被定为：

> **雷欧并不是要让地球永远依赖他，而是让被他保护的人最后能自己站起来。**

### Prelude — 托奥尔

正式开战前先把控制权交给托奥尔：玩家需要交替按左右键，让他靠自己的双腿继续跑。

这个操作会在结尾形成回环。

### Phase 1 — 最后的圆盘生物

- 布莱克恩多用火焰和巨角近身冲撞。
- Z / Enter 可以在冲撞近身时主动迎击巨角。
- `HORN GUARD` 被打掉后，正常攻击窗口扩大。

### Phase 2 — 人质

布莱克指令抓住托奥尔以后，雷欧 **真的停手**，并在剧情中承受布莱克恩多的攻击。这里不安排“雷欧被处决→复活”，因为那会重复其他路线。

随后控制权直接从雷欧手里拿走，交给孩子们：

- 玩家用方向键从布莱克指令没有看住的位置接近。
- 失败方向会被察觉，成功则让包围越来越近。
- 最后由玩家按 Z，让托奥尔咬住布莱克指令并抢走黑色水晶。

他们不是援护 NPC，也不给雷欧 Buff；**这一段本身就是他们自己的战斗。**

### Phase 3 — 水晶

抢到的黑色水晶作为一个真实 ITEM 放入玩家物品栏。

玩家亲自选择它后，雷欧把命令水晶扔回布莱克恩多，完成最后的圆盘生物战。随后还有黑星逼近与射击光束演出。

## Ending — 向太阳出发

高潮之后不再追加更大的友情光束。

结尾主动降下来：海、船、夕阳、托奥尔和凤源。开场那个必须依赖雷欧的孩子，到最后已经知道摔倒以后怎么自己站起来；凤源也不再把地球看作暂住的地方。

最终标题：**向太阳出发**。
