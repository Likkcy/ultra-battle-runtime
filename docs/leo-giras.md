# 雷欧线 01：基拉斯兄弟 / 马格马星人

这场战斗的重点不是“两个怪兽 = 两倍弹幕”。

第一阶段用 `TWIN LINK` 表示红、黑基拉斯的围攻同步。敌方回合里，特殊冲阵逼近时按 `Z / Enter` 可以主动迎击；成功迎击直接破坏围攻同步。同步越低，玩家输出越有效。

打空第一阶段联合 HP 后不会结束战斗：马格马星人持剑入场，两头基拉斯继续从左右支援。第二资源改为 `MAGMA COMMAND`；佩剑斩击也能在近身时进行 PARRY / SABER BREAK。

设计原则借鉴优秀《Undertale》Boss 战：防守回合也能主动改变战局；ACT 改变下一轮规则；第二阶段新增角色与规则，而不只是加速。
