# 基里艾洛德人Ⅱ — v0.9 战斗设计

## 定位

迪迦初版核心遭遇之一，按“区域 Boss”制作。目标不是单纯增加弹幕密度，而是让玩家同时管理 **位置、地狱之门、进攻节奏**。

## 机制一：HELL GATE

- GATE 跨回合保留。
- 敌方回合中 GATE 缓慢增长。
- GATE 越高，玩家核心受到的向上拖拽越强。
- 玩家触碰场内金色光点会降低 GATE。
- 被拖到战斗框顶部会受到伤害并被弹回下方。
- GATE 到达 100% 时触发 Gate Rupture：一次带有明确安全缺口的向下冲击；随后 GATE 重置到 58%。

## 机制二：模仿

基里艾洛德人会记录玩家上一类有效进攻：

- ATTACK -> 格斗
- SKILL -> 光线

连续同类进攻：`ADAPTED`，伤害降低。
切换类别：`BREAK`，伤害提高。

第二阶段的适应更强，因此玩家不能只用一种最优输出循环。

## 迪迦 ACT

- 看向门扉：降低少量 GATE + 增加下一轮预警。
- 站稳：下一轮削弱门的拖拽。
- 驳回：明显降低 GATE、清空模仿，但提高敌人进攻性。

## 设计原则

这场战斗的目标是让 Boss 改变“如何玩菜单”和“如何玩敌方回合”两侧，而不是仅增加 HP 与弹幕数量。
