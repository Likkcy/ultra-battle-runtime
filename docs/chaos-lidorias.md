# 混沌利多利阿斯 — 双路线战斗设计

## 目标

同一只怪兽必须支持：

1. 普通击败路线。
2. 高斯月神模式的非致命净化路线。

不能把“饶恕”做成重复点菜单。

## 高斯路线循环

```text
玩家回合
→ 选择 呼唤 / 接近 / 守护
→ 开启下一轮净化领域
→ 敌方回合同时出现：
   - 白色攻击弹：躲
   - 混沌碎片：追上并净化
→ CALM 上升或下降
→ 回到玩家回合
→ CALM 100%
→ 满月光波解除锁定
→ MERCY
```

### 路线冲突

- 对怪兽造成直接伤害：CALM -18。
- 玩家被击中：CALM -4。
- 净化一个混沌碎片：CALM +13。
- 碎片重新回到混沌核心：CALM -6。

因此普通攻击与净化不是可以同时无代价推进的两条数值条。

## 普通路线

没有净化领域时，混沌碎片对玩家有伤害。只需要躲避敌方回合，然后按普通规则攻击怪兽 HP。

## 后续可优化

- 混沌碎片根据 CALM 逐渐从紫黑转为浅蓝。
- CALM 越高，利多利阿斯的攻击动作越迟疑，弹幕节奏产生可见变化。
- 满月光波制作独立全屏净化演出，而不仅是 CSS 淡化。
- 高斯不同形态可以改变净化效率和动作选项。
