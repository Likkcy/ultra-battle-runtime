# 银河路线：超级古兰德王（v1.9）

这场战斗不再把“救出美铃”当成一条抽象进度条。

## 第一阶段：装甲外部 / 意识传递

银河无法靠正面攻击直接打穿超级古兰德王。使用【呼唤美铃】后进入意识空间。

意识空间中存在四种不同颜色的记忆之光：

- 小时候
- 银河神社
- 各自的梦想
- 并肩作战

第一次把某段记忆送回美铃中心时，会触发对应的记忆回响，并为 `MISUZU / RESONANCE` 提供主要进度。重复记忆只提供少量共鸣。普通潜入每轮出现三段记忆；【再往里面】会一次出现四段，但黑暗攻击明显更强。

设计上参考的是“通过具体记忆唤回一个人”，而不是单纯收集资源。四段共同记忆全部重新产生共鸣后，进入小光与美铃的专属对话演出。

## 小光 / 美铃对话

对话强调两个人从小相识、各自拥有梦想、彼此并非单向保护关系。美铃真正害怕的不是小光离开，而是自己被留在原地；小光则不要求她追随自己，而是让两个人各自向前，未来再相遇。

对话结束后两人的光丝真正连接，束缚美铃的黑暗锁链破碎，随后返回现实战场。

## 第二阶段：美铃解放 / 联合作战

伙伴支援从“偶尔出现一个可接的光点”升级为两层：

1. 每回合更多可接取的支援光。接到后提供护持、回复少量生命与 EN，并对古兰德王造成明显反击伤害。
2. 伙伴会周期性直接进行交叉火力，Battle Box 中能看到横贯战场的支援光束，同时实际削减 Boss HP。

因此救出美铃以后，战斗的感觉应当是“终于所有人一起拆掉这副重甲”，而不是银河继续单独作战。
