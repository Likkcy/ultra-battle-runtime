# 下一场候选：混沌利多利阿斯（设计草案）

目标：首次把“选择奥特曼”真正变成玩法分歧，而不是数值皮肤。

## 迪迦 / 普通路线

- 按常规 HP 胜利条件战斗。
- 敌方回合重点是躲避利多利阿斯本体冲撞与混沌粒子。
- HP 归零后进入普通 Victory。

## 高斯 / 双路线

高斯仍然可以正常攻击并击败敌人；同时多出一条真正独立的饶恕路线。

### Calm / 混沌度

兼容饶恕的怪兽拥有第二条隐藏状态：`calm`。

- 攻击敌人：正常扣 HP，但会让安抚更困难。
- 使用观察、呼唤、保护等行动：为下一轮安抚创造条件。
- 敌方回合无伤或完成安抚目标：增加 Calm。
- Calm 达到阈值后，满月光波可以直接触发 Mercy 结局。

### 新敌方回合：净化拦截

场地里同时存在两类物体：

1. 普通白色攻击弹：仍然需要躲避。
2. 混沌碎片：朝怪兽核心移动。

普通角色只需要活下来。

高斯在选择“安抚”后会进入月神净化状态：

- 主动接触混沌碎片不会受伤，而是将其净化。
- 净化成功增加 Calm。
- 让混沌碎片抵达怪兽则增加躁动，后续攻击变快。
- 这让饶恕路线的敌方回合目标从“只顾自己躲”变成“保护 / 净化怪兽”。

### Mercy Finisher

Calm 达标后使用 `满月光波`：

- 不造成 HP 伤害。
- 进入短暂的稳定光线阶段。
- 成功后返回 `BATTLE_FINISHED.result = "mercy"`。
- 剧情侧可以把“击败”和“安抚成功”写回完全不同的变量。

这场战斗将作为后续 SillyTavern 剧情联动的首个双结局战斗样板。
